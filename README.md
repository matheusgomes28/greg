# Greg - Simple Gregorian Calendar App

Repository containing my Rust implementation of the most basic Gregorian
calendar.

- `ratatui` for the TUI UX engine.
- `sqlite` for storing the events.

## Features

- [ ] Open current month view on calendar.
- [ ] Starts the days on the right weekday cell.
- [ ] Switch between months with vim keys.
- [ ] Use `stderr` with `ratatui` to not poison current console.
